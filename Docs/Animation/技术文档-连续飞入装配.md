# 连续飞入装配

本文说明新建筑逐件入场的表现机制。功能零件边界见 [建筑功能分支](技术文档-建筑功能分支.md)，入场完成后的等级变化见 [建筑合并与局部变化](技术文档-建筑合并与局部变化.md)。

## 目标与核心方案

**最终模型保持原位，瞬态显示件从外侧连续飞入，归位时交还正式组件。** `UAssemblyFlightComponent` 不移动原零件，所以共享原点、网格根组件和嵌套组件都能精确恢复，不需要重建层级或改作者变换。

**组件只负责表现，棋盘决定一次放置何时成立、何时可合并。** 排序、发射和运动由 C++ 完成，蓝图提供拆件模型；编辑器摆放不自动播放游戏动画。

## 结构与选择边界

**收集范围是所属 Actor 自身的独立静态网格。** `CaptureParts` 不递归 Child Actor，不拆分 ISM/HISM，也不处理骨骼网格和物理模拟零件；无可用零件、选中不支持的静态网格或非法参数都报错，不能静默改成整栋显现。

**功能分支优先排除，参与标签只能缩小美术范围。** 该判断先于标签筛选；原本不可见或 Hidden in Game 的辅助件也跳过。否则隐藏楼板和触发器会被误当成建筑零件飞走。

**启动先完整校验，再统一隐藏原件并关闭其碰撞。** 不能边收集边隐藏，否则后续某个零件校验失败时会留下半栋隐藏模型。源码入口位于 `Source/Moving_Castle/Components/Animation/AssemblyFlightComponent.*`。

## 调度与运动

**按最终世界包围盒底部高度由低到高发射。** 同底部按中心高度、组件名排序，使支撑结构先入场且固定模型能复现顺序；不能用导出序号推断零件所在楼层。

**单件时长与发射间隔独立，按绝对发射时间推进。** 默认 1.2 秒与 0.08 秒形成约 15 件并发；它不是一件落稳才发下一件。低帧率可跨过多个发射时刻，不应因帧数不足漏件或把队列越拖越长。

**临时件在发射时才创建，落定即销毁。** 等待阶段只保留快照，完成后组件停止 Tick，避免显示组件数量和常驻更新成本随总零件数长期增长。

**旋转围绕零件几何中心，而不是导入枢轴。** SketchUp 零件可共用远离自身的原点；直接插值枢轴会绕大圈。起点和弧线保存在所属 Actor 空间，目标读取正式组件变换，使所属 Actor 移动或旋转时路径一起跟随。

**临时件只有显示职责，碰撞和导航开关先于赋网格设置。** `SetStaticMesh` 会触发引擎相关更新；若先赋网格再关闭资格，会把飞行几何误交给导航。导航整轮时序见 [NPC 导航](../Navigation/技术文档-NPC导航.md)。

## 完成、取消与棋盘衔接

**落定恢复正式零件原有显隐和碰撞，保留其变换、Mobility、材质与层级。** 这使终态等于作者配置，而不是近似插值结果；Reset、失败和 EndPlay 也清理临时件并恢复仍存在的原件。

**成功完成和取消必须使用不同结果。** `OnAssemblyCompleted` 只表示成功；`OnAssemblyFinishedNative` 同时覆盖成功、取消与运行中失败，供棋盘清理延迟合并以及导航释放变化计数。把取消当成功会让不完整建筑提前升级，漏发结束会让导航一直等待。

**原生成功结束通知必须是完成分支最后一次访问自身状态的操作。** 棋盘回调可以同步合并并销毁所属 Actor，通知之后继续读取组件会访问已退出生命周期的对象。

**城堡建筑关闭组件自动播放，由棋盘每次新放置时启动。** 升级结果和卡片预览也会生成同一建筑类，若依赖 BeginPlay 自动播放，它们会误播完整入场。棋盘只在成功结束后开放合并；具体失败边界见局部变化文档。

**运行错误中止并公开原因，不另播替代效果。** `LastError` 和 `LogAssemblyFlight` 记录失败；屏幕反馈可关闭，但错误不能被当成瞬间完成，否则放置规则与表现状态会分离。

## 未实现的部分与扩展准入

**实例化网格、骨骼动画和物理零件需要新的表现适配。** 增加支持前必须定义如何快照、恢复和发结束通知，不能仅放宽类型检查。通用组件的重播是状态恢复后重新开始，不提供任意时间轴跳转或逐件玩法触发。
