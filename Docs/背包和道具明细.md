# 背包和道具明细

**背包**：玩家拥有一个建筑栏一个临时建筑栏一个徽章栏

建筑栏：玩家从道具和商店获得的房间全部存在建筑栏里，建筑栏上限十个。（后续可优化点，比如建筑栏按照功能塔类型分类，每类建筑可堆叠，通过鼠标滚轮在这一类的房间槽滚动切换当前房间，这样可以不设上限）

临时建筑栏：位于建筑栏上方，平时不显示。通过道具获得的房间如果建筑栏数量到达上限会进入临时建筑栏，只有临时建筑栏的房间进入建筑栏才能被使用，不然会一直处于溢出状态。临时建筑栏可以是牌叠起来的形式，没有上限。但建筑栏如果满了，就无法通过商店购买房间。商店购买的房间也一定不会进入临时建筑栏。

徽章栏：上限可携带六个徽章。每一次游戏结束可以全部继承到下一轮。

**道具**：分为房间组类，徽章类，职业类（有时间再做），主塔等级越高刷出高稀有度的道具概率越高
