# 建筑卡牌表现

本文约定建筑卡牌如何把色号、视差、真实建筑和闪卡箔光合成在同一张牌上。建筑身份和等级模型见[建筑定义与模型](技术文档-建筑定义与模型.md)，交易规则见[经济与房间商店](技术文档-经济与房间商店.md)。

## 目标与边界

- **卡牌用红、黄、蓝、绿和高对比的对角数字表达匹配属性。** 色号始终可读，名称、等级和交易信息各有位置。箔光与稀有度各自表达独立的表现信息。
- **商店是首个接入面。** 新效果不改变出牌、买卖、价格、放置或合成。建造栏的小尺寸线框继续使用 `UCastleBuildingPreviewSubsystem`，避免把高清彩色捕获的成本扩散到战斗 HUD。
- **闪卡是表现，不是商品属性。** 当前用商店内的箔光预览对照同一组商品；不更换商品、不修改描述、不决定稀有度、不写存档。

## 核心方案

**卡窗内只有真实建筑是 3D 捕获，合成后的整张牌再做平面透视。** 透明建筑图夹在有视差的远近图层之间。箔光独立贴在牌框和纹样上，色号和文字压在箔光之上。最后把这些元素合成同一张有透明边缘的牌面，再绕牌中心倾斜。玩家看到的是手里转动的牌和窗内有深度的景，而不是在固定矩形里旋转模型。商店本身不进入 3D 世界。

## 结构与职责

| 层 | 职责与边界 |
| --- | --- |
| `UCastleShopWidget` / `UCastleShopOfferSlotWidget` | 托管 6 个商品卡座、一体化底部价格条、只读合成提示及箔光对照开关；不构造捕获场景。 |
| `UCastleShopCardWidget` | 消费只读建筑描述与捕获结果，管理短点购买与拖拽赏牌分流、回正和牌面排版；不改商品，也不持有玩法状态。 |
| `UCastleCardPortraitSubsystem` | 复用正式建筑定义和棋盘尺寸，在隔离的摄影场景取景，负责静态缓存、当前互动牌的捕获和资源释放；不读取交易状态、鼠标或箔光设置。 |
| `M_CastleCardFace` / `M_CastleCardPerspective` | 前者合成卡窗和局部箔光；后者把 Retainer Box 合成的整张牌投影回屏幕，不解释建筑、色号或交易信息。 |

## 取景、透明与生命周期

- **取景基于真实等级模型，预览不运行玩法。** 不从关卡中截取已放置的演员，不拍棋盘、天空、标签或功能碰撞。独立灯光和镜头让牌面不会随着地图昼夜、主视口曝光或其他卡片变化。
- **建筑颜色与覆盖范围分开处理。** `SceneColor (HDR) in RGB, Inv Opacity in A` 给出线性颜色和反向不透明度。合成时使用 `1 - A` 作为覆盖率，不能拿 RGB 的亮暗扣黑底。若色彩已经乘过覆盖率，不能再乘一次，否则屋檐等细边会变暗；显示转换由牌面统一负责。
- **远近层次主要用美术分层，不给整个卡窗开相机景深。** 远景可画得软，近景可轻遮建筑，但 UI 层不会接收建筑的影子，也不参与 3D 遮挡。只有需要真实接触阴影的台座等几何，才随主体进入捕获；没有这项需求时使用建筑本身的底座。
- **静止卡只读缓存，任一时刻只有当前拖动或回正的卡请求动态视角。** 静止图不能被动态目标覆盖，否则两张同名卡会一起转。回正完毕、交互被取消、移除卡片或关闭商店时解绑，离开世界时释放摄影场景。建筑捕获限频；同一动态纹理写入新画面后也要重绘整牌合成层。首次入队是等待态；缺资产、初始化或捕获失败则明确报错，不拿旧图、其它模型或线框冒充。
- **共用的是画面，不是交互状态。** 目前色号、名称和箔面不改变拍到的几何、材质；同定义、等级和尺度共享静态图。若建筑材质将来按玩法色或数字变体，必须把实际影响渲染的值加入缓存键，不能让先渲染的图污染其它牌。

## 持牌交互、透视与箔光

- **悬停不动，短点购买、拖出 ≥ 6px 进入 3D 倾斜赏牌。** 左键在卡面按下并在局部位移小于 6px 且仍位于卡面内松手时，视为快捷点击购买（与点击卡座下方价格条走同一交易入口）；位移达到或超过 6px 后进入 3D 赏牌，倾角取决于相对按下点的局部位移，不取决于光标离卡面中心多远，按住期间可拖出卡片，松手后平滑回正且不触发购买。正在回正途中再次抓牌直接续接拖拽态，避免误买。失去捕获、刷新商品、移除或关闭商店则立即回正并清理当前交互。
- **拖向哪一侧，那一侧就退远，对侧抬近。** 例如向右拖时左边靠近，向下拖时上边靠近。在局部位移转成共享倾角时统一反转双轴；不能给投影、视差或摄影单独反号，否则同一次拖动中牌框和卡窗会朝相反方向转。
- **整牌四角用透视投影，不用二维旋转或剪切冒充。** Retainer Box 只合成牌面、角标、名称、等级和卡窗，购买按钮留在外面。绕牌中心的水平轴和垂直轴转动，让近边显得更长、远边更短。投影限制在原卡位内，防止裁掉角标或盖住相邻卡；输出保留预乘 Alpha，卡外区域透明。
- **同一倾角同时驱动整牌、远近视差、真 3D 建筑和箔光。** 远近图层移动幅度不同，建筑相机小幅绕行以露出侧面，箔光移动的是反射条带。卡框、文字随整牌一起投影，但不随窗内的景物滑动；建筑图也不能再作为一层插画做第二次 UV 位移，否则会显得打滑。箔光不能盖住对角数字或淹没玩法色。
- **沿用分层思想，不依赖外部资源包。** `ParallaxCardMaterial` 的平面插画位移和效果遮罩可当参考；其 `_UI` 样例实际是 `Surface` 材质，也不拥有建筑的遮挡信息，直接套用会丢掉 UMG 输入和真 3D 的边界。

## 扩展准入

- **牌背与翻牌独立于建筑卡窗。** 公开版本使用原创「色号堡垒」图案；原版 UNO 标志和牌背不进入未经授权的资产。牌背、抽卡演出、背包接入和稀有度数据不属于首版。
- **增加透明或会发光的建筑特效前先验证 Alpha。** 玻璃、带后处理的发光和抗锯齿边缘可能具有不同的色彩与覆盖范围，不能假定所有 UE 捕获源的 A 都含有同一种数据。需要新通路时保持浅色与深色背景切换不出现暗边、方底或丢失镂空。
