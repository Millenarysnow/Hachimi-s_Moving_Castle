# 建筑属性配色

场上房间和商店中的同一张建筑卡使用相同的红、黄、蓝或绿。屋面负责远距离识别，带家族色的柱身和结构色带负责侧面识别。建筑身份与等级由[建筑定义与模型](技术文档-建筑定义与模型.md)管理，邻接产生的替换屋面见[建筑语义 PCG](技术文档-建筑语义PCG.md)。

## 配色依据

**颜色来自每张卡的 `FCastleBuildingDescriptor::Color`。** 同定义、同等级、同网格的两栋建筑可以同时显示不同颜色。主塔的四面格各自带有玩法色，继续使用格面自己的配色。

**瓦片沿用作者的色阶和分布。** V4 的陶瓦按五个材质槽分配深浅，深色向灰紫过渡，浅色向暖米色过渡。以属性色重新生成这些色阶，釉面、瓦底和棚布各保留自己的对比度。直接把已有蓝瓦与黄色相乘会压暗蓝通道，同一纯色覆盖全部瓦片则会抹掉同一坡面上的变化。换色作用在固有色，表面粗糙度、金属度、法线、遮蔽及实际光照仍由原材质决定。

## 构件的颜色归属

**普通房、箭塔、炮塔、农田、气球塔、蜂巢和盾塔使用各自真实的美术部件。** 作用范围包括陶瓦、棚布、彩釉和有意承担属性色的柱身、柱带或结构嵌板。平板普通房也需要可见的属性色部位。共享石料、木料及金属时，同时核对作者节点用途和材质。以整个建筑、整个屋角或某个 RGB 色域作为选区，会染到木板、五金、植被、蜂蜡和屋脊上的金饰。

**叠层屋面的颜色按作者图集分区。** 四格屋面把瓦片与边饰合在一个材质槽里，五族共用一张基础色图，盾塔另有图集。换色依据 UV 色块或显式遮罩读取对应色阶。作者纹理中的细部变化仍进入固有色。金色区域的边缘同样属于装饰，远景纹理过滤时也要维持这一边界。

## 实例、动画和预览

**共用材质，颜色随组件。** 正式蓝图中的原件以及棋盘新装配的墙、屋角、坡顶和叠层件都读取所属建筑的颜色。上下层交界按实际拥有该视觉件的房间取色。独立房间相接后仍可各自显示自己的属性。飞入、合并及局部替换动画创建临时网格时，须复制与源件相同的配色数据，否则着陆时会跳色。保留网格及材质的身份，供合并动画判断零件能否就地复用。

**彩色卡图缓存包含玩法色。** 商店摄影场景使用与游戏相同的建筑初始化；静态和拖动卡图均须对应本张卡。纯法线轮廓与固有色无关，可以按几何共享。详见[建筑卡牌表现](技术文档-建筑卡牌表现.md)。
