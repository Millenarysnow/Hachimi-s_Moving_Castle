# 对话与新手教程

本文说明通用类 Galgame 对话框架、独立新手教程关卡与正式局首次登岛对话的设计边界。正式单局流程见 [导演系统](技术文档-导演系统.md)，双操作模式与拆除菜单见 [操作模式与建筑拆除菜单](技术文档-操作模式与建筑拆除菜单.md)，主界面左下角入口见 [主界面 HUD 与三态切换](技术文档-主界面HUD与三态切换.md)，空岛进入事务见 [空岛框架](技术文档-空岛框架.md)。

## 目标与非目标

**目标：** 提供一套支持左右双立绘、打字机逐字揭示、二段点击推进、分支选项与动态键位提示的轻量类 Galgame 对话框架，并用独立关卡 `TutorialMap` 与线性步骤配置实现城主哈基米德与机械狗旺财的完整新手教学，同时在 `MainMap` 首次登上三类空岛时触发对应剧情短对话。

**非目标：** 不制作多线网状 AVG 引擎、配音口型同步、好感度或回放历史；更不把新手教程的固定发牌、固定商店货架或专属“复制功能房”三选一混入 `MainMap` 正式肉鸽导演流。

## 核心方案

**将“通用对话演出（`UCastleDialogueSubsystem`）”与“新手教学编排（`ACastleTutorialDirector`）”分层解耦，并把教学主流程放在独立关卡 `TutorialMap` 中运行。** 这样任何系统（包括 `MainMap` 空岛首次触发）都能零耦合播放一段多句对话，而新手教程需要的定制商店、定制奖励和城主亲自出战也不会污染 `UCastleDirectorSubsystem` 的正式肉鸽规则。

## 结构与依赖边界

代码位于 `Source/Moving_Castle/Castle/Dialogue/` 与 `Source/Moving_Castle/Castle/Tutorial/`，界面资产位于 `Content/MovingCastle/UI/Dialogue/` 与 `Content/MovingCastle/UI/Tutorial/`，教学关卡为 `Content/MovingCastle/Maps/TutorialMap`。

- **`UCastleDialogueSubsystem` 只管理当前剧本播放、打字机状态与选项回调，不感知任何建造、商店或战斗逻辑。** 台词数据由线性配置的 `UCastleDialogueScriptDataAsset` 提供。违反此边界会让通用对话框反向耦合教程特判，无法在 `MainMap` 空岛复用。
- **`TutorialMap` 严禁加入 `UCastleDirectorSettings::AutoStartMaps`。** 新手教程由关卡内的 `ACastleTutorialDirector`（读取线性步骤资产 `UCastleTutorialConfigDataAsset`）驱动；若同时启动正式肉鸽导演，两套系统会争抢节点生成、商店权限与波次结算。
- **教程主塔在 `TutorialMap` 保留一颗 HUD 心的生命下限。** `ACastleTutorialDirector` 初始化时启用主塔组件的教程锁血，最低生命为最大生命的二十分之一，对应顶部 20 格血条中的一格。敌方伤害会结算到该下限，低于下限的气球回收生命消耗会被拒绝；普通关卡不启用此规则。
- **物品 HUD 由关卡导演显式选择。** 教程挂载临时建筑栏，正式导演额外挂载徽章栏和徽章替换弹窗。统一挂载所有组件会让无徽章交互的教程常驻六个空槽。
- **台词内涉及鼠标左右键的提示必须通过占位符随当前操作模式动态解析。** 控制器默认处于经典模式（MC：右键放置/交互、左键拆除），玩家也可随时通过左下角设置切换为设计模式（动物园之星：左键放置/交互、右键拆除）。硬编码“左键建造/右键拆除”会在默认经典模式下直接误导玩家卡关。
- **配置、立绘槽、图文条目或必需 `BindWidget` 缺失时必须报错拒绝启动，严禁静默跳过教学步或回退空白占位框。**

## 类 Galgame 对话与图文百科机制

- **左右双立绘与发言焦点：** `UCastleDialogueWidget`（`WBP_CastleDialogue`）固定持有左侧立绘槽、右侧立绘槽、说话人名牌、正文富文本/文本框与分支选项容器。每句台词显式指定左右立绘贴图（可留空隐藏对应槽位）及当前发言侧（左 / 右 / 旁白），发言侧正常高亮、对侧降低明度，让哈基米德与旺财的吐槽交锋一眼可辨。
- **对话底板与点击层分别填满同一个 Overlay。** 底部面板占视口宽度 84%，金边底板承载说话人、自动换行台词和继续提示。透明按钮是底板的兄弟节点，避免 `UButtonSlot` 居中把正文压成窄条。两张立绘按 380×380 的设计基准等比缩放并贴住底板上沿，保留鼠标命中穿透。分支按钮从 WBP 样式模板读取常态、悬停和按下切图。
- **打字机二段点击推进：** 台词开始时按配置的每秒字符速率逐字揭示；揭示未完成时点击对话区（或按确认键）**立即补全整句正文而不跳句**；正文已完整显示后再次点击才推进下一句。遇到带分支选项的台词（如“城主大人亲自上阵吧 / 旺财我们走”），正文揭示完毕后展开选项按钮，点击选项跳转到目标句并在汇合点继续线性推进。
- **纯剧情对话期间收起底部建造栏。** 控制器以模态输入显示鼠标并暂停视角转动，建造栏订阅 `UCastleDialogueSubsystem` 的活动变更事件，开始时折叠，结束或取消时立即重新应用正常游戏阶段的显隐条件。折叠控件可能停止 Tick，显隐恢复必须由事件驱动。实操步骤收起对话，使用非模态目标提示并开放世界射线与建造栏输入。
- **图文介绍弹窗与 `?` 攻略收纳。** 首次介绍建造、拆除、路径编辑及幽灵或箭塔机制时，弹出金边图文面板。玩家关闭后条目收录到左下角 `?` 打开的书册，书册的箭头按钮切换已解锁条目。教程的资产生成入口沿用堡垒发布器生成对话、图文、书册和教程领奖界面，避免重新生成教程配置时恢复旧皮肤。

## 独立教程关卡流程与首次登岛触发

- **固定手牌和塔侧种子成套配置。** 教学开局和固定商店发放黄色 3 号房间。首层四面从正式四色池采样为黄色，正门和后门同为 3 号。调整色池或种子时必须一起核对首层格面，避免农田无法替换巡逻回路中段的普通房。
- **`TutorialMap` 线性教学闭环：** `ACastleTutorialDirector` 按配置表顺序推进并监听真实游戏事件验成，不在 UI 里伪造假棋盘：
  1. **开场与回路搭建**：播放开场对话后向 `PrototypeBackpack` 发放固定色号普通房手牌，依次校验主塔正门首房落成，以及正门到后门形成连通回路。
  2. **购塔与拆房换防**：发放启动资金并解锁右下角商店，固定首批商品含目标箭塔；购入后引导玩家对已放普通房打开拆除菜单将其拆回建筑栏，并在腾出或匹配的格位放上箭塔。
  3. **路径编辑与城主出战**：引导按 `P` 布置 2 个路径点并提交开环路线；对话触发二选一调侃后生成第一波教学幽灵群。玩家点击主塔派兵时，派出的城主巡逻单位头顶挂载轻量气泡控件显示“呜呜呜...”，途经箭塔触发射箭清场。
  4. **专属复制奖励、合成与经济收尾。** 清场后展示金币 +60、主塔回血和复制随机功能房间。教学解锁第 3 项，领取同色同号 1 级箭塔，再紧贴原箭塔放置触发自动合成。最后重开商店，从缺货状态刷新出固定的农田，购入后布置到巡逻路径上完成教学。
- **`MainMap` 三类空岛首次登岛对话：** 在 `UCastleGameInstance`（或本地存档设置）中记录 `Shop`、`PinballNPC`、`Gamble` 三类奖励空岛是否已触发过首次登岛剧情。`UCastleDirectorSubsystem` 完成入岛传送后检查该标记：若属首次登岛，立即调用 `UCastleDialogueSubsystem` 播放对应的哈基米德/旺财短对话并置位标记，关闭对话后无缝交还空岛交互。

## 反直觉的坑

- **堡垒业务界面统一挂在 Viewport 层。** `AddToViewport` 和 `UGameViewportSubsystem::AddWidget` 都使用 Viewport 层。`AddToPlayerScreen` 使用独立的 Player 层，始终绘制在 Viewport 层之下，`ZOrder` 只能比较同层控件。商店内对话期间商店仍全屏可见并置灰，混用两层会让商店盖住对话并挡住继续按钮。同层挂载让商店（40）、对话（70）和百科（71）按既定顺序绘制并接收输入。
- **把打字机“补全当前句”与“跳下一句”绑在同一次按下且不吃掉松手事件，会导致单击连跳两句。** 必须在同一次点击周期内严格按揭示完成状态二选一消费事件。
- **在教程等待“拆除普通房”步骤直接调用底层 `RemoveBuilding` 会跳过背包回收校验。** 教程必须监听玩家通过正式拆除菜单触发的退回建筑栏事件，保证拆下的普通房真实回到建筑栏且与正式局手感一致。

## 被否决的方案

- **在 `MainMap` 的 `UCastleDirectorSubsystem` 内加大量 `if (bIsTutorial)` 分支。** 否决：教程要求固定手牌、首次商店缺货刷新出农田以及“复制随机功能房”特殊三选一，塞进正式导演会严重污染肉鸽随机性与单局状态机。
- **制作节点图式全通用可视化任务蓝图框架。** 否决：教程流程固定且线性，过度抽象节点图只会把逻辑散落进蓝图资产，违背 C++ 主导逻辑的项目红线。

## 未实现的部分与扩展准入

**当前未实现的部分：** 角色语音播放、对话历史回看面板、跨存档槽位的教程进度云同步，以及主菜单选择进入 `TutorialMap` 的独立前端入口（主菜单后端尚未实现，当前可直接打开 `TutorialMap` 或通过控制台/菜单挂点进入）。

**扩展准入条件：** 新增教学段落或空岛剧情时，必须新增或扩展 `UCastleDialogueScriptDataAsset` 与 `UCastleTutorialConfigDataAsset` 数据行，不得在 Widget 或 `ACastleBoard` 中硬编码台词文本。
