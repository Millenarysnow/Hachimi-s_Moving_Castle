# 空岛框架

空岛框架管理战斗间的离塔访问。单局阶段和下一步节点由[导演系统](技术文档-导演系统.md)持有，房间与徽章的发放边界见[背包道具与徽章](技术文档-背包道具与徽章.md)。

## 职责与扩展

**空岛基座提供空间、到达锚点和离开传送门。** 原生类位于 `Castle/SkyIslands`。玩法子类在 `OnInitializeIsland` 中准备本岛交互和资源，只依赖上下文与基座能力，避免玩法类之间出现交叉依赖。

**正式空岛由 `DA_DirectorConfig` 统一登记。** `SkyIslandClasses` 将 `Rest`、`Shop`、`NPC`、`Gamble` 分别绑定到 `ACastleRestSkyIsland`、`ACastleShopSkyIsland`、`ACastlePinballNPCSkyIsland`、`ACastleGambleSkyIsland`。奖励节点按单局种子、关数和节点序号从后三类中选一种，休息节点固定进入 `Rest`。对应映射缺失或类无效时，导演报错并保留编辑阶段和当前节点。

**导演独占进出岛和步数提交。** 非 Shipping 构建的 `CastleEnterSkyIsland` 在可操作的编辑阶段直接指定四类之一，读取本局正式配置，复用节点入岛的生成、传送和离岛推进事务。即使本步没有空岛节点，仍可用同一套流程验证正式配置。

**岛初始化通过后才传送玩家。** 导演保存入岛前 Pawn 变换和视角，隐藏建造面，清除当前节点。传送、初始化或建造面准备失败时应留在塔侧，避免玩家进入半初始化空间。空岛阶段保留飞行和视角。

## 交互和离开

**交互接口由实际准星命中的 Actor 或组件实现。** 物件验证当前控制器和岛屿上下文，明确返回原因。控制器统一在非模态状态读取配置键，默认 E。传送门广播离开意图，导演在 Tick 里先准备下一批节点，再传回主塔、销毁岛并推进。将销毁延迟到交互已返回，可避免回调仍在访问被销毁的组件。

**共享奖励由导演接到既有账户和控件。** 空岛调用基座请求一次免费换批、打开待领房间或发放徽章。导演验证请求来源是当前空岛，库存和模态输入继续走原有入口。子类内各自维护玩法状态，避免重复建立商店、房间选择和徽章替换业务。

## 休息空岛

**三个实体台座分别记录本次访问的领取状态。** `ACastleRestSkyIsland` 用专属配置提供免费回血、金币和额外房间商店。回血由主塔生命组件计算实际恢复量并同步气球。满血也可以消耗本岛这次机会，方便玩家确认台座状态。

**房间商店台只授予本次访问的一批免费商品。** 导演在本岛维护换批状态，休息台只在打开成功后标记已领取。玩家关闭界面后，台座和常规商店键均拒绝重开。离岛清除临时商店状态并返回主塔编辑阶段，此时主塔普通商店按常驻规则可再次打开。

## 商店空岛

**实体货位从两类配置池按本岛种子抽样。** `ACastleShopSkyIsland` 保证至少一个房间组和一个徽章，其余台座按池条目抽取并优先展示不同商品。每次进岛生成三至四个商品，正式配置为四个台座。空池、失效引用和非法数量或价格由岛初始化拒绝，保证导演传送后看到完整货架。

**确定房间组和徽章在交互时结算。** 房间组先准备全部牌面，扣费后按背包规则写入建筑栏和临时栏。徽章满六枚时，子系统接受待替换项即完成交易。玩家在替换界面选槽或舍弃均保留购买结果。发放接口拒绝时退还金币并保留货位。

**万能卡直到确认才扣费。** `UCastlePendingRoomReward` 校验所选牌面后调用商店的授权钩子，按当前余额结算。入包成功后提交售罄，入包失败时由商店退款。取消仅关闭选择，金币和台座不变，同一商品保留待领奖励及已抽中的候选。升级等普通奖励沿用原有免费领取流程。

**房间组台展示与发牌配置分层。** `UCastleRoomGroupDataAsset` 必须显式配置白、蓝、紫、金、炫彩之一；商店在初始化时校验稀有度和 `DA_ShopSkyIsland` 的网格、五档材质引用。任一房间组漏配或档位越界都拒绝发放或初始化，因为没有有效档位时无法保证台座展示与所售商品一致。

**全部房间组共用包底轴心网格和母材质。** `/Game/MovingCastle/Model/Items/RoomPack/SM_RoomPack` 底面位于局部 Z=0，材质实例只替换五档基础色和 ORM。网格缩放 14.5 倍，包高约 190.4 cm。导入后印字正面指向局部 +Y，左货位 Yaw=0°，右货位 Yaw=180°，使包装正面朝中央通道。

**售罄只改变该货位的动态材质参数。** 确定发牌或万能卡确认完成后，`SoldAmount` 从 0 切至 1，基础色去饱和并压暗，粗糙度提高、金属度降低，箔膜法线仍保留。网格和 `QueryOnly` 可见性碰撞继续生效，价格牌显示 `SOLD OUT`，重复准星命中继续返回已售罄提示。弹窗取消、金币不足和发牌失败都保留原稀有度材质与可购买状态。徽章台继续使用既有球体和着色。
