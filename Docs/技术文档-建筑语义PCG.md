# 建筑语义 PCG

本文记录建筑美术与功能面如何由棋盘三维邻接语义派生，相关合并动画见[建筑合并与局部变化](Animation/技术文档-建筑合并与局部变化.md)，导航时序见[NPC导航](Navigation/技术文档-NPC导航.md)。

## 目标与非目标

系统为正式完成放置的建筑计算屋顶、顶平楼板、周围护栏和跨格通道目标，并以局部变化动画应用差异。它覆盖上下叠放、平面四邻、确定性梯子择格、可逆恢复和动态梯子导航。本期不改动或离线切分导入蓝图，也不接入旗帜、藤蔓等装饰。

**LV5 明确不参与本期部件 PCG。** 目前 LV5 逻辑占用仍为单格，但临时复用 LV4 八格模型；在正式占格与专属模型接通前，不能把八格部件猜映射到单格。每次布局求值都会按指南输出带建筑路径、类名和原因的 Warning，保留 LV5 原模型与占用；其单格占用仍用于其他等级的邻接判定。

## 核心方案

`UCastleBuildingPCGSubsystem` 把棋盘占用转换为纯语义邻接，再由规则集生成完整目标键；`UCastleBuildingPCGComponent` 只在目标验证通过后隐藏原始组件并创建独立动态件。原始蓝图网格始终保留，因而邻居移除可以按作者初始显隐精确恢复。

## 结构与依赖边界

`Castle/PCG/` 定义 `FCastlePCGPartAnnotation`、六向邻接、规则、规则资产和动态建筑组件。建筑只持有 `BuildingPCG`，棋盘通过 `OnLayoutCommitted` 通知布局变化，棋盘不实现 PCG 规则。规则资产明确指定 LV1、LV2 和封闭平板资源，缺失资源时返回错误。

几何提取先把网格包围盒变换到棋盘坐标，再识别角色和覆盖格。薄护栏可以覆盖一个或两个格；跨两格护栏在单侧连接时隐藏整体原件，连接格放 LV1，未连接格复用本蓝图已有单格护栏网格。该组合避免修改导入资产和程序化裁切。

## 语义行为

同色或同数字的六邻建筑可通行，异色异数字封闭，斜角不产生邻接。上方建筑存在时下层对应格屋顶隐藏。上下可通行的一对建筑按坐标字典序或确定性噪声选择唯一 LV2 梯子格，其余重合格使用封闭平板；上下不可通行时全部使用封闭平板。平面可通行邻接双方的交界护栏各自替换为 LV1，并在 `GameplayRoot` 生成隐藏功能桥；不可通行时生成隐藏阻隔盒。

目标键按坐标和面排序，重复求值不会重播动画。自动布局事件只重算发生变化格及其六邻；公开 `Recompute` 仍可用于完整重算。未完成飞入的建筑不进入语义场。

## 动画与导航时序

`UBuildingMergeComponent::StartChange` 拒绝把结果自身作为来源。PCG 因此先创建瞬态、无碰撞、无导航资格的旧件快照 Actor，快照包含当前运动姿态和等待件，再提交目标显隐和动态件，最后调用 `StartChange` 并销毁载体。快照或目标计划失败时不接管显隐。

所有动态美术件挂在视觉分支并关闭碰撞/导航；桥、平板、阻隔和梯子挂在 `GameplayRoot`。梯子由 `UCastleLadderLinkComponent` 注册双向连接，接驳偏移来自 LV2 实测几何：梯底/梯顶为 `(-58.317,150,0/560)`，下层接驳为 `(-58.317,40,0)`，上层接驳为 `(40,40,560)`。两端不向下投影或扩大吸附范围；没有动态 Recast 或无效 Link ID 时整轮提交失败。

共享路径采样只承认本次 Recast 走廊中的梯子 Link。即使查询点恰好落在 Link 锚点，也必须用走廊 Link 端点精确匹配后生成上下攀爬区间；未知 CustomLink 不会被当作普通直线。TestMap1 的 NavMeshBoundsVolume 顶面和高度已覆盖多层建筑，当前高度 6000cm、顶面 Z=3000cm。

## 反直觉的坑

- 名称或组件序号不能决定语义；显式 `PCGRole=` 标签优先，拼写非法会拒绝整轮提取。
- 动态件不能替换原始网格引用；否则动画接续和邻居移除会失去恢复依据。
- Link 已登记不等于路线可用；必须等待动态 Recast 构建完成，并验证两端投影和路径走廊。
- **Visibility 命中的美术顶面不等于可走楼板。** `ACastlePatrolRoute` 把射线实际命中点直接作为路径点；屋顶、炮台等美术件可以被选中，但不参与 NavMesh。命中点高出功能楼板并超出投影范围时，路线会在路径点投影阶段整条失败，不能据此判定 PCG 交界桥断路。定位时应对比命中组件、命中高度与功能楼板上的跨界路线；不能靠扩大投影或把点移到另一层掩盖错误表面。取点表面的行为由交互层定义，PCG 不替它自动选择楼层。
- `FName` 名称表索引不能作为跨进程噪声种子；噪声按通道字符、种子和格坐标稳定哈希。

## 被否决的方案

离线切分跨格护栏会侵入 31 份导入蓝图和目录资产，已由运行时单格护栏复用取代。整件隐藏后保留未连接半段会错误移除护栏。把建筑自身传给 `StartChange` 会触发自引用拒绝，已由瞬态快照载体取代。导航层扫描附近梯子会把普通跨层路径误判为梯子，已由 Recast 走廊证据取代。

## 未实现与扩展准入

未来若要将 LV5 接入 PCG，必须先接通其正式占格和专属模型，并定义覆盖格集合；在此之前保持明确 Warning 跳过。新增其他语义角色时需同时定义覆盖格、方位、恢复和失败边界，并保持棋盘只发送布局事件、导航只消费已登记连接。
