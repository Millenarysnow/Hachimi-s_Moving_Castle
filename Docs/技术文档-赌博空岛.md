# 赌博空岛

赌博岛提供轮盘赌桌、老虎机和气球回收机。进岛、离岛与关数提交归[空岛框架](技术文档-空岛框架.md)，卡牌和徽章的正式发放归[背包道具与徽章](技术文档-背包道具与徽章.md)中的既有入口。

## 机台归属

**`ACastleGambleSkyIsland` 持有单岛状态。** 三台机台分别由实现空岛交互接口的组件接收准星命中。机台只操作当前玩家的背包和单局账户、当前世界的主塔与当前游戏实例的徽章。`DA_GambleSkyIsland` 保存玩法参数及奖励引用，配置校验通过后才开放交互。

**老虎机有独立的房间奖励定义池。** 奖励可包含加速房，使用正式建筑定义生成可用卡牌。奖励配置由赌博岛持有，因此主图商店的出牌集合可以独立调整。确定牌与选择型万能卡都走同一个房间组发放入口，徽章由空岛基座接入现有六槽和满槽替换流程。

## 轮盘暂存与结算

**微缩区保存完整房间描述符。** `FCastleMiniPlacementBoard` 用三维整数坐标记录原牌。首张放底板原点，后续至少有一面相邻且同色或同数字。匹配读取牌面数字，战斗中由徽章得到的有效数字不会影响拼放。撤回最后一张保持剩余房间的放置关系，关闭面板或离岛会批量退回全部未下注牌。

**开转同步提交，指针动画展示已确定的落点。** 转动前计算可能的返还总张数并检查整数范围。黑、红命中返还总计两份，绿命中总计三十份，押错销毁该批暂存。复制沿用完整描述符，背包的批量接口负责库存校验和临时栏排队。批量写入成功后才清掉原暂存，动画结束不会再次发奖。

**轮盘和老虎机分别持有由空岛种子派生的随机流。** 轮盘基础比例为 18 黑、18 红、1 绿，只将押中色的权重乘以 `1 + LuckBonus`。老虎机对每个中奖档乘以同一系数，未中奖档基础权重固定，归一化后占比下降。幸运值为零时保留原表比例，一台机器消耗随机数也不会改变另一台的抽样。

## 奖励窗口与气球

**轮盘采用原生 `BindWidget` 面板与占位 WBP。** WBP 定义布局和样式，C++ 从当前建筑栏枚举卡牌，再按牌面枚举合法格位。放牌或撤回后重建选项，因为临时栏补位会改变主栏索引。面板使用控制器的模态输入入口，关闭后恢复飞行，现有房间和徽章奖励窗口沿用相同的输入门控。

**主塔组件拥有可扣生命的最终判定。** 回收机在确认金币可入账后，调用 `TryConsumeBalloons` 扣一个基础气球的生命。组件拒绝会导致最后一个气球消失的操作，回收机仅在扣血成功后发金。回收不计为敌人攻击。

**开发验收载体独立保存往返位置与交互生命周期。** 它沿用同一岛类、机台交易和奖励控件，离岛后清除临时输入组件。正式局的空岛选择、进出与关数仍由导演管理，赌博岛注册随空岛集成统一完成。
