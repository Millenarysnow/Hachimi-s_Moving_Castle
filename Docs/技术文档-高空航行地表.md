# 高空航行地表

远景地表给固定在世界坐标中的城堡提供持续航行的视觉参照。抬头是天空，俯视能看到海岸、河谷、山脊和森林从下方掠过。

## 目标与边界

**城堡、玩法场景和远景面片都使用固定世界变换。** 地貌向固定航向的反方向滚动。玩家可以独立转头、横移和升降，镜头朝向不参与航向计算。

**地表、水体和植被属于背景渲染。** 首版范围是高度场地表、海洋与内陆水面、按气候着色的群系及远景林冠。地下体素、洞穴、流体模拟、单株植被交互和地面玩法在本系统边界之外。

## 核心方案

**用固定细分平面承载 GPU 生成的地貌。** GPU 在进入关卡时为一段可无缝平铺的地貌生成高程与地表数据图及其逐级降采样的 mip 链。顶点材质读取高度并通过 WPO 只改变 Z，像素材质读取同一位置的地貌数据进行着色。运行期间，C++ 只推进并传递有界的采样偏移。地貌随偏移一起经过网格，网格和玩法世界的变换始终固定。

**滚动连续性来自周期采样。** GPU 噪声的底层格点和纹理采样都按同一周期环绕。航程参数按完整地图周期分别对 X、Y 取余，跨周期时山脊、岸线和林冠连续。景色并非永不重复；固定航线返回同一组采样坐标时会重复。

## 结构与依赖边界

**`Plugins/AerialTerrain` 是独立运行时插件。** `AAerialTerrainBackdrop` 持有网格和显示材质，并控制航程参数与地貌数据图的生命周期。地图通过摆放该 Actor 接入。插件只使用引擎模块，与城堡、导航、战斗、关卡导演和玩家 Pawn 没有代码或资产引用。地表没有碰撞、导航、实时阴影或玩法射线响应。

**环境雾由地图布置。** `MainMap` 的地表海平面与大气的零海拔对齐，约在城堡下方 3 km。体积雾保留少量散射，高度雾限制最大遮盖，避免近俯视区域的群系、水线和林冠被洗成同一颜色。插件移植时仍由目标关卡提供天空和雾。

**必填资源和尺寸须在启动时校验。** 错误配置在日志中标明 Actor 或资产及原因，地表渲染保持未初始化。地表不会把缺失的资源解释成其他一种地貌。

## 地表、群系与植被

**参考 Minecraft 1.21 的职责划分，独立实现适合高空视角的二维地貌。** Minecraft 的 `NoiseRouterData`、`OverworldBiomeBuilder`、`SurfaceRuleData` 和 `VegetationPlacements` 分别提供了大陆度、侵蚀度与山脊，按多维气候确定群系，依地形条件确定表层，以及按群系和高度放置植被的参考。本系统使用自己的周期噪声、参数和配色，直接产生二维高度与气候场。

**地形与气候分别采样，再在地表规则里汇合。** 大陆尺度的噪声决定深海、浅滩、海岸和内陆。侵蚀度与脊线决定山地、平原、低地与谷地。温度和湿度决定干草地、草甸、阔叶林与寒带针叶林的覆盖，高度和坡度进一步划出积雪、岩壁及滩地。连续混合让群系边缘在高空视角下自然过渡。

**森林按冠层覆盖表现。** 根据群系、坡度、水线和聚集噪声决定林冠密度。在地表材质中以确定的冠层斑块表现林地，让植被和地形同速掠过，并在远处收敛成林地色块。

**水面来自地形高度与局部水位的比较。** 海洋使用统一海平面，低地河谷与湖盆使用各自的水位。可见表面取地形与水位中较高者。浅岸与深水的色差来自水深，水与岸共用几何和地貌坐标，避免单独水网格的接缝和相对漂移。

## 关键不变量

- **顶点、群系、河岸和林冠共享地貌坐标。** 若只平移颜色，山脊与海岸线将彼此滑离。若只平移网格，有限边缘会移动进视野。
- **几何采样尺度由实际顶点间距决定，不由航程或镜头转向切换。** 网格 UV1 保存横纵相邻顶点的间距比例，WPO 据此读取并插值相邻 mip。顶点过疏却读取原始高度图，会使同一远山横移时反复冒出或丢失小峰。着色中的坡度和水线使用相同的地貌坐标，像素覆盖范围比网格间距更大时才进一步降频。包围盒仍须覆盖最大位移，避免转头时突然裁掉地貌。
- **可见地表必须在天空球内侧，并先融入对应方向的天空亮度，再按固定视距裁边。** 天空球太小时会直接遮掉远端地貌。裁边前颜色若没融合完全，就会留下网格轮廓；逐帧抖动的遮罩会使覆盖范围不稳定。`M_AerialTerrainSurface` 显式使用 Sky Atmosphere 亮度混合，避免对其额外叠加同一套大气透视；地图高度雾和体积雾仍然作用于画面。
- **渲染坐标的卷动与预烘台阶无关。** 纹理格点连续插值，航程每帧以游戏时间推进。贴图周期可回绕，玩家的局部位移和旋转只通过正常三维透视改变画面。

## 扩展条件

更换航线时沿地貌二维坐标累积航程向量，保持现有位置与偏移连续。若需要完整路线中的独有地标或更大的无重复航程，可按同一世界采样坐标流送多张高度图。仅在出现近地镜头或地面交互时引入单株植被、地形碰撞或更细的网格。
